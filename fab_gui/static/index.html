Live play

Play against the unified trained agent with the coach in this UI and the Talishar board in a Chromium window (same as CLI live play). Requires Talishar backend on :8080, Talishar-FE on :5173 (python start_talishar.py), Playwright (pip install playwright && playwright install chromium), and a trained unified agent. The in-page embed and new-tab links often stay blank with the local Vite dev server — use Chromium. Import deck and opponent on tabs 1–2 first.
